Scraping and analysing 10,000+ EPL match and player records to uncover team consistency, goal patterns, and player efficiency across multiple seasons.

## 📌 What This Project Does

- Scraped and cleaned **10,000+ match and player-level records** across multiple EPL seasons using `pandas.read_html()`
- Engineered **5+ custom KPIs** — points-per-match, goal differential trends, and player efficiency ratios
- Conducted EDA to quantify team consistency and goal contribution patterns
- Visualised findings through **10+ Matplotlib charts** for clear, interpretable insights
